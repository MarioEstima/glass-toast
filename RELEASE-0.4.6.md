# Glass Toast 0.4.6 — destaque cinza no ícone

Esta versão deixa o destaque atrás do ícone cinza nos estilos `solid` e `soft`, independentemente do tema ou do tipo do toast. A cor usada é `rgba(128, 128, 128, 0.35)`. O estilo `bare` continua sem círculo.

A cor do ícone, o fundo e o texto do toast e as animações não mudaram. Nenhuma prop ou tipo da API foi alterado.

Para ajustar a cor ou a opacidade do destaque, altere a constante `ICON_HIGHLIGHT` em `src/components/ToastContent.tsx`.

```bash
npm install glass-toast@0.4.6
```
