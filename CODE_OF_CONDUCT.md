# Code of Conduct

## Our Commitment

Glass Toast is an open-source project built around collaboration, learning, and respectful technical discussion.

We are committed to providing a welcoming environment for everyone who contributes to or interacts with the project.

## Expected Behavior

Contributors and community members are expected to:

* Be respectful and professional.
* Communicate constructively.
* Assume good intentions.
* Accept constructive criticism.
* Focus discussions on ideas and technical decisions.
* Respect different levels of experience.
* Help maintain a welcoming and inclusive community.

## Unacceptable Behavior

The following behavior is not acceptable:

* Harassment or discrimination.
* Personal attacks or insults.
* Trolling or deliberately disruptive behavior.
* Threats or intimidation.
* Publishing private information without permission.
* Unwelcome sexual or discriminatory comments.
* Deliberately creating a hostile environment.
* Any other behavior that would reasonably be considered inappropriate in a professional open-source community.

## Project Discussions

Technical disagreements are expected in an open-source project.

When disagreements occur, discussions should remain focused on:

* The problem being solved.
* Technical evidence.
* Project goals.
* Maintainability.
* Developer experience.
* Cross-platform compatibility.

Personal criticism should never replace technical discussion.

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, pull requests, commits, or other contributions that violate this Code of Conduct.

Repeated or serious violations may result in temporary or permanent removal from project participation.

## Reporting

If you experience or witness unacceptable behavior, report it privately to the project maintainers rather than creating a public issue.

For security-related concerns, follow the process described in [`SECURITY.md`](SECURITY.md).

## Scope

This Code of Conduct applies to project repositories, issues, pull requests, discussions, and other spaces directly associated with Glass Toast.

## Attribution

This Code of Conduct is inspired by common standards used by open-source communities and adapted for the Glass Toast project.
